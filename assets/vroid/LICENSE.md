# VRoid sample models — CC0 1.0

Ранние образцы VRoid Studio, которые pixiv выпустила под **CC0** (авторские права сняты):
https://vroid.pixiv.help/hc/en-us/articles/4402614652569 (раздел «CC0 license models»).
Файлы взяты с OpenGameArt (https://opengameart.org/content/vroid-studio-cc0-models) и из
https://github.com/madjin/vrm-samples (vroid/beta). Текстуры уменьшены `tools/shrink_vrm.py`.

| Файл | Исходная модель |
|---|---|
| `elf.vrm` | AvatarSample_F |
| `dark.vrm` | Darkness_Shibu (AvatarSample_D Darkness) |
| `villager_e.vrm` | AvatarSample_E |
| `villager_g.vrm` | AvatarSample_G |

Загрузка — @pixiv/three-vrm (MIT). Анимации — клипы Quaternius (CC0), перенесённые на VRM (`modules/vrmKit.js`).
