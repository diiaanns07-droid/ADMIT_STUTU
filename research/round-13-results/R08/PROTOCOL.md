# R08 · раунд 13 · протокол сравнения (зафиксирован ДО запуска моделей на challenge-наборе)

Всё ниже — синтетические/агентские данные. Качество на реальных обращениях: real_data_NOT_EVALUATED.

## Методы (без новой подстройки гиперпараметров)
1. keyword — `heuristic.py` (основы STEMS не менялись с a26e598, до корпуса).
2. logreg — чистая логистическая регрессия на n-граммах; конфигурация раунда 12 (l2 1e-5, 24 эпохи, lr0 0.5;
   лучшая «чистая» по validation), переобучается детерминированно на тех же данных.
3. hybrid — logreg + признаки словаря; закреплённый артефакт раунда 12 `data/model.json.gz`
   (l2 1e-4, 12 эпох, keyword_scale 1.0). Для CV переобучается с той же конфигурацией.
4. nb — справочно (alpha 0.1).
5. hybrid+abstain — те же оценки hybrid плюс правила отказа раунда 13 (ниже).

## Наборы
- A. leave-family-out CV (основной протокол на корпусе): группа = (метка, family) — парафразы и переводы
  одной проблемы; 56 групп; 5 фолдов, детерминированно (sha256(seed:группа), по меткам по кругу).
  Обучение на 4 фолдах, проверка на пятом; метрики по объединённым предсказаниям + разброс по 5 фолдам.
  Это строже, чем split раунда 12: в проверке нет семейств из обучения.
- B. test раунда 12 (split по шаблонам) — EXPLORATORY: просмотрен дважды, 87 % его семейств есть в train.
- C. пробный набор раунда 12 (112) — EXPLORATORY: ошибки разобраны в FAILURES.md.
- D. challenge_r13_v1 (134) — заморожен (sha256 b25a6a19…), запускается ОДИН раз по этому протоколу.

## Метрики
per-class и per-language precision/recall/F1, macro-F1, матрица ошибок; coverage и точность при отказе;
«уверенные ошибки» = неверная метка без отказа при score ≥ 0.9 (hybrid/logreg) или ≥ 2 совпадениях словаря
(keyword). Интервалы — только для CV (разброс по 5 фолдам, 56 независимых групп); для challenge — числа и
перечень ошибок без интервалов (n мал, разметка одним агентом).
Для многотемных сообщений: «безопасный исход» = отказ ИЛИ метка из {label} ∪ also_labels.

## Правила отказа (abstain) раунда 13 — определены до challenge
- R1 multi_topic: совпадения словаря у ≥ 2 разных меток, кроме other.
- R2 latin_script: латинских букв > 50 % (транслит, иностранный язык) — модель обучена на кириллице.
- R3 low_margin: разница двух лучших softmax-оценок < M; M выбирается на validation раунда 12 (сетка
  0.05…0.50): минимальный M, при котором точность непринятых к отказу ≥ 0.95; иначе M с максимальной точностью.
- R4 no_content: < 3 значимых символов (уже было).
Отказ не меняет поля контракта: label = лучшая метка (подсказка), score = null, score_kind = "abstain:<причины>",
needs_review = true. Синтетическая версия всегда needs_review = true.

## Объяснение подсказки
Не причина и не LLM-текст: совпавшие основы словаря для выбранной метки и до 3 признаков-«начал слов»
с наибольшим вкладом (вес выбранной метки − вес второй метки) × значение признака.
