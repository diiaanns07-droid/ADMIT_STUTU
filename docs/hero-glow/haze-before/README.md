## Что держит её белой — один кадр, по очереди выключено (`node tools/hero_haze_ab.mjs --heroes elf`)

| Вариант | Пересвет рамки | Лицо (σ) |
|---|---|---|
| как в игре | 5,1 % | 0,93 (0,05) |
| без глубины резкости меню | 5,7 % | 0,93 (0,06) |
| без мягкой кромки волос | 5,4 % | 0,93 (0,05) |
| без сцены витрины (портал, частицы, пол) | 3,3 % | 0,93 (0,05) |
| без bloom | 0,4 % | 0,83 (0,11) |

DOF, прозрачная кромка волос и портал — не причина. Пелену даёт bloom: на эльфийке под светом витрины выше порога
(1,0) лицо, волосы и шёлк — светлые материалы × ключ 2,0 × почти белый цвет стихии.
