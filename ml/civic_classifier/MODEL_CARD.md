# Model card — civic_classifier (R08, раунд 12, Астана)

> **Демонстрационная модель.** Обучена и оценена только на синтетических и написанных агентом сообщениях.
> Качество на реальных обращениях жителей: **NOT_EVALUATED**. Разметка — агентская (Claude, R08) по
> `LABELING_GUIDE.md`, **не** экспертная человеческая.

## Назначение
Подсказка модератору категории сообщения жителя (`roads`, `sidewalks`, `transport_stops`, `lighting`,
`landscaping`, `other` — ровно `ui/civic_feedback` CATEGORIES). R06 сохраняет подсказку рядом с выбором
жителя и **не меняет** категорию. Модель не публикует, не отклоняет, не определяет срочность или исполнителя.

## Модель
- Версия: `civic-clf-logreg-kw-cf4464341-pe9ba054a`; файл `data/model.json.gz` (≈105 КБ, JSON, без pickle),
  sha256 содержимого хранится в файле и проверяется при загрузке.
- Метод: мультиклассовая логистическая регрессия (SGD, L2=1e-4, 12 эпох, усреднение весов) на символьных
  2–5-граммах + префиксах слов (log1p, L2-норма) **плюс** признаки совпадений словаря эвристики (масштаб 1.0).
- Выбор: среди NB (4 alpha), logreg (3 настройки) и logreg+словарь (3 масштаба) — по macro-F1 на validation.
- Выход: `score` = max softmax, `score_kind="softmax_max_uncalibrated"` — не вероятность.
- `needs_review`: всегда `True`, пока `training_data_status` начинается с `synthetic` (порог 0.30, подобранный на
  синтетической validation по цели точности 0.90, не переносится на реальных жителей). Для будущей модели с
  реальной оценкой: `needs_review = score < threshold or label == "other" or language ∉ {ru, kk}`.
- Fallback: нет/повреждён файл модели -> эвристика по ключевым словам, `score=None`, `needs_review=True`,
  `model_version="civic-clf-heuristic-fallback-v1"`. Импорт не обращается к сети.

## Известные ограничения
- Транслит латиницей не поддержан (5 из 6 ошибок в этом стиле); сленг и невиданные слова («колдобины»,
  «тополя», «саженцы») уходят в `other`.
- Словарные ловушки: «пешеходам» у светофора -> sidewalks, «строительной площадки» -> landscaping,
  «жарық бар» -> lighting; намерение (благодарность, вопрос о сроках) не моделируется.
- Классы `other` и `lighting` — самые слабые по точности на test (0.72 и 0.70).
- Казахские шаблоны и пробные фразы не проверены носителем языка. Детектор языка R06 считает казахский
  текст без специфических букв русским.
- Обезличивание по шаблонам удаляет телефоны, e-mail, ИИН, ссылки; имена и адреса не удаляются.
- Автор шаблонов, пробного набора и словаря один — это даёт эвристике и гибриду преимущество на этих данных.

## Как получить реальную оценку
Правовое основание и согласие на выгрузку обращений -> обезличивание и ручная проверка -> разметка двумя
людьми по `LABELING_GUIDE.md` (Cohen's kappa) -> временной split -> `python -m ml.civic_classifier train` на
новом корпусе (формат JSONL как `corpus_synthetic_v2.jsonl`) -> `training_data_status` без `synthetic`.

## Воспроизведение
`python -m ml.civic_classifier build-corpus` · `train` · `evaluate` · `predict "текст"` — см. `research/round-12-results/R08/RUN.txt`.
Переобучение на Linux/CPython 3.13 воспроизводит файл модели побайтно (тест `test_r08_train.py`).

## Раунд 13 — честная оценка (артефакт модели тот же, payload 104c46a6…)
- Воспроизведение без сети: корпус, split, model.json.gz и model_alt_nb.json.gz пересобираются побайтно
  (`python -m ml.civic_classifier audit`).
- Аудит: 87 % сообщений test раунда 12 принадлежат «семействам» (парафразы/переводы), которые есть в train;
  85 % сообщений корпуса содержат основу словаря своей метки. Test и пробный набор раунда 12 — exploratory.
- Основной протокол — leave-family-out CV (5 фолдов, 56 групп), гиперпараметры раунда 12 без подстройки:
  словарь 0.861 ≈ гибрид 0.856 > logreg 0.738 > NB 0.581 (macro-F1, среднее по фолдам); гибрид лучше словаря в
  2 из 5 фолдов → **превосходство гибрида не подтверждено**; обученная модель без словаря хуже во всех фолдах.
- Замороженный challenge_r13_v1 (134 агентских сообщения; один запуск): словарь 0.679, гибрид 0.736 (macro-F1);
  общие провалы — адресные ловушки, отрицание, подстроки словаря, транслит. Не доказательство преимущества.
- Отказ (abstain-r13-v1): несколько тем, латиница, малая разница оценок (M = 0.25 по validation), пустой текст.
  На challenge: покрытие 0.649, точность принятых 0.862, уверенных ошибок 10 вместо 16.
- Объяснение: совпавшие основы словаря и «начала слов» с наибольшим вкладом; не причина. Только словарь модели —
  тексты жителей и персональные данные в объяснение не попадают (тест).
