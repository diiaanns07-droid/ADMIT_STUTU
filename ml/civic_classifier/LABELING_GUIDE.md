# Правила разметки категорий (R08, civic-v1)

Метки совпадают с `ui/civic_feedback/service.py` `CATEGORIES` (CODE_BASE_SHA 56538a3).
Разметку синтетического корпуса и пробного набора выполнял агент (Claude, роль R08) по этим правилам.
Это **не** экспертная человеческая разметка.

Главное правило: метку определяет **объект проблемы**, а не место, где она замечена.

| Метка | Что относится | Пограничные случаи |
|---|---|---|
| `roads` | проезжая часть, ямы/выбоины, асфальт после раскопок, разметка (в т.ч. «зебра»), светофоры, дорожные знаки, искусственные неровности, снег/лёд/вода **на проезжей части**, перекрытие дороги без знаков | светофор -> roads (не lighting); разметка перехода -> roads |
| `sidewalks` | тротуары, плитка, пешеходные дорожки и их отсутствие, бордюры, пандусы, подземные/надземные переходы, проход перекрыт забором стройки, лёд/лужи **на тротуаре** | пандус/бордюр у перехода -> sidewalks |
| `transport_stops` | остановочные павильоны, скамьи и навесы на остановках, табло, перенос/закрытие остановки, автобус не останавливается на остановке, снег/лёд на посадочной площадке | частота маршрутов/расписание без проблемы остановки -> other |
| `lighting` | уличные фонари не горят/мигают/горят днём, тёмные дворы и дорожки без света, повреждённые опоры освещения | фонарь **у остановки** -> lighting |
| `landscaping` | деревья (вырубка, посадка, обрезка), газоны, скверы и парки, детские и спортивные площадки, скамейки и урны в парках/дворах, клумбы, благоустройство двора | скамейка **на остановке** -> transport_stops |
| `other` | всё вне пяти категорий: вывоз мусора, шум, бездомные животные, отопление/вода, вопросы о сроках, благодарности, нецелевые сообщения | вопрос «когда закончат ремонт дороги?» без описания проблемы -> other |

Пометки в данных: `ambiguous: true` — если правило требует выбора между двумя объектами;
`language`: `ru`, `kk`, `mixed` (смешение RU/KK в одном сообщении).
